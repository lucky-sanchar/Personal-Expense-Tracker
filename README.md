# 💸 Personal Expense Tracker (Web App)

A dynamic and interactive Web Application built with Python and Streamlit to help users track, manage, and analyze their daily expenses. Developed as part of the Internship Mini Project Assignment.

## 🚀 Features
- **Add Expenses:** Easily add new expenses with an interactive calendar (Date), Category, Title, and Amount.
- **View Expenses:** Interactive dataframe/table displaying all recorded expenses.
- **Category Filter:** Smart dropdown to search and filter expenses by specific categories with real-time total updates.
- **Total Calculation:** Automated real-time calculation of overall spending.
- **Monthly Summary:** Aggregated monthly data presented with visual **Bar Charts**.
- **Delete Expense:** Select and remove incorrect or old entries seamlessly.
- **Data Storage:** Persistent backend data storage using JSON.

## 🛠️ Technologies Used
- **Language:** Python
- **Frontend/UI Framework:** Streamlit
- **Database/Storage:** JSON (`Expenses_Track.json`)
